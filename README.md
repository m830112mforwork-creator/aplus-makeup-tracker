# 國小英語 補課派工與進度追蹤系統

## 這是什麼

沿用原本 Excel「請假補課追蹤表」的欄位設計，改成三個角色（老師／助教／管理職）可以同時在線上填寫、即時看到彼此狀態的網頁工具。單一 HTML 檔案 + Firebase 即時資料庫，部署方式跟妳之前的 Library Time、代課排課系統一樣。

## 第一步：建立新的 Firebase 專案

1. 前往 https://console.firebase.google.com ，用妳的 Google 帳號登入
2. 「新增專案」→ 輸入專案名稱（例如 aplus-makeup-tracker）→ 一路下一步建立完成
3. 左側選單「建構」→「Firestore Database」→「建立資料庫」
   - 位置選 `asia-east1`（台灣近）
   - 模式隨便選都可以，下一步會整個覆蓋掉
4. 左側「Firestore Database」→「規則」分頁 → 把本專案 **`firestore.rules`** 的內容整段貼上去 → 發布
   - 這一步別跳過。Firebase 預設的「測試模式」規則 30 天後會自動失效，到時候系統會整個打不開；`firestore.rules` 不會過期
5. 左側「專案設定」（齒輪圖示）→ 往下滑到「你的應用程式」→ 點選 `</>` 網頁圖示 → 幫應用程式取個名字 → 註冊
6. 會出現一段 `firebaseConfig = { apiKey: ..., authDomain: ..., ... }`，把這一整包貼給我，或是妳自己打開 `app.js`，找到最上面的 `FIREBASE_CONFIG`，把裡面的值換成妳複製的內容

## 第二步：部署到 GitHub Pages

跟妳之前的做法一樣：開一個新 repo（例如 `aplus-makeup-tracker`），把 `index.html` 和 `app.js` 兩個檔案上傳上去，設定 GitHub Pages 從該 repo 的根目錄發布即可。（`README.md`、`.rules` 那兩個檔上傳與否都不影響系統運作。）

## ⚠️ 目前沒有密碼保護

目前 `app.js` 的 `REQUIRE_PASSWORD` 是 `false`，搭配的 `firestore.rules` 也是完全開放的。這是刻意的設定，不是漏做，但請知道它代表什麼：

- **任何拿到網址的人，都能看到所有學生的姓名、請假原因、補課紀錄，也能修改或刪掉任何資料**，不需要密碼
- GitHub Pages 的網址是公開的，只是沒有連結的人不容易找到

所以在開密碼保護之前：**網址只在部門內部群組傳，不要貼在對外的文件、網站或公開社群。**

要開密碼保護時看下面的附錄，程式的部分已經寫好了。

## 附錄：之後想開密碼保護時

做法是「全部門共用一組密碼」——在 Firebase 建一組共用帳號，網頁把帳號自動帶入，使用者只需要輸入密碼。五個步驟：

1. Firebase Console 左側「建構」→「Authentication」→「開始使用」
2. 「Sign-in method」分頁 → 選「電子郵件/密碼」→ 啟用（上面那個開關打開就好，下面的「電子郵件連結」不用開）→ 儲存
3. 切到「Users」分頁 →「新增使用者」
   - 電子郵件填 **`staff@aplus-makeup.local`**（不需要是真的信箱，但**必須跟 `app.js` 裡的 `SHARED_ACCOUNT_EMAIL` 一模一樣**）
   - 密碼填要發給全部門的那組共用密碼（**Firebase 規定至少 6 碼**）
4. 左側「Firestore Database」→「規則」→ 改貼 **`firestore.with-password.rules`** 的內容 → 發布
5. 打開 `app.js`，把最上面的 `REQUIRE_PASSWORD` 從 `false` 改成 `true`，重新上傳到 GitHub

第 4、5 步要一起做，只做一邊系統會連不上資料。

做完之後，沒有密碼的人連資料庫都連不上，不只是看不到畫面而已。

### 換密碼

Firebase Console →「驗證」→ Users → 找到 `staff@aplus-makeup.local` → 右邊三個點 →「重設密碼」。改完之後所有人下次開系統都要重新輸入新密碼。

### 共用密碼的限制

- **系統分不出是誰做的**：大家用同一組帳號登入，Firestore 層面看不出某筆紀錄是哪位老師改的。紀錄裡的「老師姓名」是右上角自己填的，可以隨便打。
- **密碼外流等於全開**：離職或密碼流出去，就要用上面的方式換密碼、再重發給大家。
- 之後如果想升級成「每個人各自的帳號」（可以追蹤誰改了什麼、也能單獨停用某個人），跟我說，改起來不會動到現有資料。

## 系統邏輯說明

- **老師**：填寫學生請假與缺課資訊、指派補課內容（表單最上面有「套用範本」：綜合範例、書寫型、朗誦型、補考型、觀念解答型，會填入缺課核心課程、課本、單元和指派補課內容，再改成學生的實際情況；範本內容在 `app.js` 的 `FORM_TEMPLATES`），並從時段表格挑選**補課日期**與時段（以週顯示實際日期、可切換週次；**最快只能排明天**，要留一天給助教交接，所以今天的格子顯示「今天不可排」，但整週仍照常顯示；名額按當天計算，同一個每週時段 9/17 和 9/24 各有自己的名額；額滿或已過的日期不能選）。送出後可以隨時產生「傳給教學部：申請時段」或「傳給教學部：異動通知」的文字。助教填完成果之後，老師會在自己的紀錄裡看到全部內容（實際補課日期、驗收成果、作業補交狀況、助教備註），確認無誤後按「查核並簽名」結案——對應補課合作說明裡教師須預備的第 4 項。標題旁會顯示還有幾筆待查核，也可以用「待我查核」快速篩出來。助教點名記錄學生未到時，卡片會標紅「未到待改期」，按「修改」換日期或時段，或直接儲存＝排到下週同一天的同一時段。每張卡片有「修改」：可以改內容、**改期**（重新點日期與時段，原本那天的名額自動釋出，存完直接跳出填好的異動通知）、**取消補課**（紀錄保留、名額釋出、可恢復）或**刪除**（打錯的紀錄才用，無法復原）。
- **助教**：最上面是「本週補課總覽」，週一到週五每個時段有誰要來補課一目了然（含狀態、可切換週次，也可勾選「顯示全部助教的補課」看其他助教的班）。點總覽裡的學生會捲到下面那張卡片並閃一下；點到別的助教的學生會提示。下面是只屬於自己的待處理清單（已取消的不會出現），補課當天先點名（準時出席／遲到／未到）：遲到或未到會提醒打電話給教學老師；選「未到」不算補完課，只記一筆未到紀錄，交給老師改期。學生有來就填寫成果，並可一鍵產生要傳給家長的訊息文字、標記「已通知家長」。填完之後也看得到老師查核簽名了沒。
- **管理職**：點「管理職」分頁要先輸入管理職密碼（同一個瀏覽器關閉前不用重輸，頁面上有「鎖定管理職」）。這個密碼只是擋老師、助教誤入，**不是資安保護**：資料庫規則仍開放、程式碼是公開的，懂技術的人仍可繞過；程式裡只存密碼的雜湊值，換密碼時要重新產生 `app.js` 的 `ADMIN_PASS_HASH`。儀表板顯示總數／待補課／逾期／未到待改期／待老師查核／已完成／已取消，逾期（排定的補課日期過了、助教還沒填到課紀錄）的列會自動標紅；下方是所有紀錄的總表，附搜尋框（學生、班級、老師、助教、單元都能搜）、狀態篩選和助教篩選；總表每一列都有「修改」，功能和老師的一樣。最下面是助教時段與名額的設定區（新增 Kevin、Kelly 的時段就是在這裡做），每個時段有「備註」寫使用的輔導教室（老師選時段時看得到，申請時段的訊息也會帶出；改一格時會問要不要套用到同一位助教的其他時段），時段自己輸入（例如 3:00-4:00；打成 3:00~4:00 也會自動整理成同一種寫法），表格裡的時段、名額可以直接改（改時段時，之後已經排進來的學生會一起改到新時間，已補完課的紀錄保留原本時間），時段也可以刪除（表格的「之後已排」是今天起已經排進這個每週時段、還沒補課的人數）；刪掉還有學生排著的時段時會先提醒。
- **補課合作說明**：補課制度的職責分工——助教可做的四型職責（書寫、朗誦、補考、觀念解答）、英語教師須預備的 4 件事、助教須預備的 4 件事。老師和助教頁最上面也各有一條對應的提示，點「補課合作說明」可以跳過來看完整版。內容要改的話在 `index.html` 的 `view-rules` 區塊。

右上角的名字是**下拉選單**：老師頁選的是**英語總導師**（那一頁是給英語總導師看的），清單會列出「我登記的」加上「我是英語總導師的」紀錄，因為可能由別人幫忙開單；助教只能選時段設定裡有的名字（助教的紀錄就是靠這個名字配對的）；老師可以「＋ 新增名字」，打的名字跟名單上只差大小寫時，會自動對到名單上的寫法。

手機上表格會自動變成一筆一張卡，不用左右拉。

存檔失敗（網路斷線、規則沒貼對）會跳出紅色錯誤訊息，表單內容會保留；按下送出後到存檔完成前，按鈕會鎖住，不會因為連點變成兩筆。所有日期都用台灣本地時間計算。

## 一筆紀錄的流程

```
老師登記 → 待補課 →（助教點名出席／遲到，填完成果）→ 待老師查核 →（老師簽名）→ 已完成
            │  ↓ 補課日期過了（隔天起）助教還沒填
            │ 逾期未補
            │
            ├─（助教點名：未到）→ 未到待改期 →（老師修改：換日期／時段，或直接排到下週同一時段）→ 回到待補課
            │
            ↓（修改 → 取消補課）
          已取消 ──（修改 → 恢復補課）──→ 回到待補課
```

**沒有老師簽名就不算結案**，管理職儀表板的「待老師查核」會一直掛著。逾期的算法：排在 9/16 的補課，9/16 當天還沒填不算，9/17 起助教還沒填出席／遲到或未到，就算逾期。

## 目前還沒做、要跟妳確認的地方

1. **時段表一開始是空的**：系統不會自動建立預設時段。上線前請管理職先到「管理職 → 助教時段與名額設定」把每位助教（Jocelyn、Kevin、Kelly⋯）的時段、名額、教室備註輸入完成，老師才選得到時段，助教也才能在右上角選到自己的名字。
2. **逾期的定義**：排定的補課日期過了（隔天起），助教還沒填這次的到課紀錄就算逾期；記了「未到」的會變成「未到待改期」，不算逾期。改期後改看新的日期。
3. **名字仍然不是登入身分**。右上角已改成下拉選單，打錯字配對不到的問題解決了；但查核簽名、取消、刪除記的都是右上角選的名字，任何人都能選別人的名字去操作——目前沒有登入驗證，這是必然的限制，要真正綁定身分得先做帳號登入。
4. **補課類型還沒變成欄位**。補課合作說明裡的四型職責（書寫／朗誦／補考／觀念解答）目前只是文字說明，老師是打在「指派補課內容」自由欄位裡。如果想讓它變成可選、可統計的欄位（例如看這學期補考型佔多少），跟我說。

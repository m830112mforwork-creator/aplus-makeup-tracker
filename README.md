# 國小英語 補課派工與進度追蹤系統

## 這是什麼

沿用原本 Excel「請假補課追蹤表」的欄位設計，改成三個角色（老師／助教／主任）可以同時在線上填寫、即時看到彼此狀態的網頁工具。單一 HTML 檔案 + Firebase 即時資料庫，部署方式跟妳之前的 Library Time、代課排課系統一樣。

## 第一步：建立新的 Firebase 專案

1. 前往 https://console.firebase.google.com ，用妳的 Google 帳號登入
2. 「新增專案」→ 輸入專案名稱（例如 aplus-makeup-tracker）→ 一路下一步建立完成
3. 左側選單「建構」→「Firestore Database」→「建立資料庫」
   - 位置選 `asia-east1`（台灣近）
   - 模式先選「以正式環境模式啟動」（等一下第三步會貼上正確的規則）
4. 左側「專案設定」（齒輪圖示）→ 往下滑到「你的應用程式」→ 點選 `</>` 網頁圖示 → 幫應用程式取個名字 → 註冊
5. 會出現一段 `firebaseConfig = { apiKey: ..., authDomain: ..., ... }`，把這一整包貼給我，或是妳自己打開 `app.js`，找到最上面的 `FIREBASE_CONFIG`，把裡面的值換成妳複製的內容

## 第二步：部署到 GitHub Pages

跟妳之前的做法一樣：開一個新 repo（例如 `aplus-makeup-tracker`），把 `index.html` 和 `app.js` 兩個檔案上傳上去，設定 GitHub Pages 從該 repo 的根目錄發布即可。（`README.md`、`firestore.rules` 上傳與否都不影響系統運作。）

部署完成後，回到 Firebase Console →「驗證」→「設定」分頁 →「已授權網域」，把 GitHub Pages 的網域（`妳的帳號.github.io`）加進去，不然在那個網址上會登入失敗。

## 第三步：設定共用密碼（**這步做完，系統才真的受保護**）

系統採「全部門共用一組密碼」。實作上是在 Firebase 建立一組共用帳號，網頁把帳號自動帶入，使用者只需要輸入密碼。

1. Firebase Console 左側「建構」→「Authentication」→「開始使用」
2. 「Sign-in method」分頁 → 選「電子郵件/密碼」→ 啟用（上面那個開關打開就好，下面的「電子郵件連結」不用開）→ 儲存
3. 切到「Users」分頁 →「新增使用者」
   - 電子郵件填 **`staff@aplus-makeup.local`**（不需要是真的信箱，但**必須跟 `app.js` 裡的 `SHARED_ACCOUNT_EMAIL` 一模一樣**）
   - 密碼就填妳要發給全部門的那組共用密碼（至少 6 碼）
   - 新增
4. 左側「Firestore Database」→「規則」分頁 → 把本專案 `firestore.rules` 檔案的內容整段貼上去 → 發布

做完這四步，沒有密碼的人連資料庫都連不上，不只是看不到畫面而已。

### 之後要換密碼

Firebase Console →「驗證」→ Users → 找到 `staff@aplus-makeup.local` → 右邊三個點 →「重設密碼」。改完之後所有人下次開系統都要重新輸入新密碼。

## ⚠️ 共用密碼的限制（請知道一下）

- **系統分不出是誰做的**：大家用同一組帳號登入，所以 Firestore 層面看不出某筆紀錄是哪位老師改的。紀錄裡的「老師姓名」是右上角自己填的，可以隨便打。
- **密碼外流等於全開**：離職或密碼流出去，就要用上面的方式換密碼、再重發給大家。
- 之後如果想升級成「每個人各自的帳號」（可以追蹤誰改了什麼、也能單獨停用某個人），跟我說，改起來不會動到現有資料。

## 系統邏輯說明

- **老師**：填寫學生請假與缺課資訊、指派補課內容，並從時段表格挑選補課時段（會顯示每個助教/時段的剩餘名額，額滿的時段無法選取）。送出後可以隨時產生「傳給教學部：申請時段」或「傳給教學部：異動通知」的文字。
- **助教/輔導老師**：只會看到指派給自己（姓名要跟主任在「時段設定」裡填的助教姓名完全一致）的待處理清單，完成補課後填寫成果，並可一鍵產生要傳給家長的訊息文字、標記「已通知家長」。
- **主任**：儀表板顯示總數／待補課／逾期／已完成，逾期（缺課日期超過 3 天還沒實際補課）的列會自動標紅；下方是所有紀錄的總表，以及助教時段與名額的設定區（新增 Kevin、Kelly 的時段就是在這裡做）。
